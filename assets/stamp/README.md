# Stamp artwork

The stamp draws its own posy of flowers. To put a picture there instead — a
photograph, or a drawing when the artist delivers one — save it here as
`couple.jpg` or `couple.png` (portrait, roughly 4:5, a few hundred pixels wide
is plenty) and run:

    python3 tools/build-stamp-art.py

Remove the file and run it again to go back to the flowers.
